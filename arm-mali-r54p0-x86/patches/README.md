# Arm virtual-device patch set

The six patches in `arm-virtual-device/` are extracted from `patches_for_virtual_device.zip`.

Arm's Virtual Platform How-To Guide states that this patch set enables Mali 5th Gen Kbase builds on non-Arm CPU virtual devices and that the supplied patches apply cleanly to r54p0. The patch files are kept as an untouched reference copy.

OpenCode must never edit these files in place. If a patch does not apply, stop at the patch checkpoint and record the full error in `research/decisions.md`.
